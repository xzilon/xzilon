## 💫 About Me

I'm a first-year **Robotics and Automation Systems Engineering** student at **KMUTNB** and a programmer on the **iRAP** robotics team, where I build vision systems and ROS 2 software for competitions such as **ABU Robocon**.

I enjoy the whole path from math to motion: kinematics on paper, firmware on a microcontroller, and a camera feeding it all in real time.

| | |
|---|---|
| 🔭 **Currently working on** | Inverse kinematics robot arm |
| 🤖 **Focus areas** | Robot kinematics, computer vision (OpenCV), ROS / ROS 2, embedded systems |
| 🌱 **Learning** | ROS 2 navigation & control, more advanced kinematics |
| 💬 **Ask me about** | C/C++, Python, ESP32 / Arduino, ROS 2, Linux, 3D printing |
